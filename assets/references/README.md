# Reference Assets

Put new source materials here before wiring them into a render script.

Suggested subfolders:

- `images/` for new scene backgrounds, maps, or screenshots.
- `logos/` for replacement brand assets.
- `voiceover/` for human-recorded narration files if the team has rights to commit them.

After adding a source asset, update `assets/scene_assets_manifest.md` and `docs/nur2_video_handoff.md` if the asset becomes part of the video.
